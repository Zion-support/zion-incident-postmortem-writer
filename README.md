# 📝 Zion Incident Postmortem Writer

AI-assisted incident postmortems — blameless, complete, and in minutes. Part of the **Zion ITOps AI Suite (Batch 72)**.

## What it does
- Builds incident timelines automatically from alerts, deploys and chat
- Drafts blameless postmortems: impact, root cause, contributing factors, action items
- Tracks action-item completion and recurrence of similar incidents

## Key features
- Native intake from [Zion Incident Triage](https://github.com/Zion-support/zion-incident-triage)
- Templates aligned to SRE best practices (Google SRE, PagerDuty)
- Exports to Confluence/Notion/GitHub; Slack digests
- Recurrence analytics feed [Zion AI ROI Tracker](https://github.com/Zion-support/zion-ai-roi-tracker)
